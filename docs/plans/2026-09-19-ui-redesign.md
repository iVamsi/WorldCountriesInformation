# Atlas Folio UI Redesign — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan phase by phase. Steps use checkbox (`- [ ]`) syntax for tracking. Each phase ends with a build, a device check, and a commit.

**Goal:** Give World Countries Information a distinctive, cohesive visual identity ("Atlas Folio") across every screen without changing what the app does.

**Architecture:** All identity lives in `core/designsystem` (color, type, shape, motion, and four shared components). Feature screens consume tokens and components only; no feature module defines its own colors, fonts, or flag rendering. Navigation stays a single stack (Countries → Details / Quiz / Compare / Settings) with a two-pane layout on expanded width.

**Tech stack:** Kotlin 2.4, Compose BOM 2026.09 (Material 3 Expressive), Navigation 3, Hilt, Coil 3, osmdroid, Glance. New: one bundled font file (Fraunces, OFL) and AGP's first-party Compose Preview Screenshot Testing plugin. No other dependencies.

**Product truth:** `PRODUCT.md` (users, capabilities, constraints, brand commitments). Baseline screenshots: `docs/screenshots/before/`.

## Global constraints

- Min SDK 26, target SDK 37. Dynamic color (Material You) stays a user toggle; the static scheme is the brand and must look better than the dynamic one, never worse.
- Product name "World Countries Information" and the static scheme name "Explorer" stay. Don't invent a new product name. "Atlas Folio" is the internal design name only.
- Keep every capability listed in `PRODUCT.md`. Keep every existing `UiTestTags` tag and the copy the instrumentation tests match on (`Countries`, `Settings`, `Compare countries`).
- Domain layer stays free of Android imports. Feature modules never import each other.
- All colors come from `MaterialTheme.colorScheme` roles. No raw `Color(0x…)` outside `core/designsystem/Color.kt`.
- All text sizes in `sp` through `MaterialTheme.typography` roles. No hand-picked `fontSize` in screens.
- Touch targets ≥ 48 dp. Every icon-only control has a `contentDescription`. Headings use `semantics { heading() }`.
- New user-facing strings ship in en, de, es, fr, hi in the same commit.
- Detekt, Spotless/ktlint, Android Lint, unit tests, and connected tests pass at every commit.
- Ponytail mode is on: the shortest diff that meets the design wins. Reuse before writing. No abstractions for one caller.

## Part 1 — Design

### 1.1 Visual direction: Atlas Folio

The app should feel like opening a well-made printed atlas: warm paper, crisp ink, flags presented as plates, facts set in a tidy reference table. It is a lookup tool first (Operate mode), so scanability and Material conventions win over decoration; the brand lives in type, color temperature, and a few precise details.

Principles:

1. **Paper and ink.** Warm off-white surfaces in light, deep ink-navy in dark. Flat tonal layering with hairline rules instead of drop shadows.
2. **Flags are plates.** Every flag is drawn the same way everywhere: 3:2, small radius, 1 dp `outlineVariant` border so white or pale flags never dissolve into the page.
3. **Two voices.** A display serif (Fraunces) for country names as headings, screen titles, and quiz prompts. Roboto for everything you scan or read at length.
4. **One accent for warmth.** Teal stays the primary (the "Explorer" identity). A new ochre tertiary marks favorites, streaks, and "Country of the Day" so the error red is only ever an error.
5. **Density for lookup.** The list is a list, not a stack of cards. Facts sit in a two-column grid, not nine stacked cards.
6. **Motion that explains.** Shared-axis transitions between stack levels, container-scale on press, nothing decorative. Respect the system animation scale.

What the old look tells us (anti-reference): 2 dp cards on every row, `primaryContainer` top bars, a diagonal gradient background, dynamic color making the palette differ per device, "Country name: Afghanistan" repeated under the title.

Usage rules:

- Page background: `background`. List rows: transparent on `surface`, separated by `outlineVariant` hairlines.
- Cards and tiles: `surfaceContainerLow`, 0 dp elevation. Hover/pressed states come from ripple.
- Search field, chips, and controls: `surfaceContainerHigh` fill.
- Top app bars: `surface` (scroll-tinted by Material), never `primaryContainer`. Contextual selection bar: `primaryContainer`.
- Favorites, streaks, Country of the Day accents: `tertiary`/`tertiaryContainer`.
- Correct quiz answer: `primaryContainer`. Wrong: `errorContainer`. Stale cache: `onSurfaceVariant` text plus a `tertiary` dot, not red.
- A unit test asserts ≥ 4.5:1 for every `on*` pair and ≥ 3:1 for `outline` on `surface`, in both schemes.

Dynamic color stays available and is respected as-is. Everything below uses roles, so it adapts.

### 1.3 Typography

Bundle **Fraunces SemiBold** (`core/designsystem/src/main/res/font/fraunces_semibold.ttf`, OFL 1.1, one static file ≈ 170 KB). Fraunces is warm, slightly wonky, and reads as "reference book" without being a Playfair cliché. Bundling (not the downloadable-fonts provider) keeps the app offline-safe and GMS-free, which `PRODUCT.md` requires. Remove the unused `open_sans.xml` downloadable font wiring (`font/open_sans.xml`, `font_certs.xml`, `preloaded_fonts.xml`, the `styles.xml` reference).

Type roles:

| Role | Family | Use |
| --- | --- | --- |
| display*, headline* | Fraunces SemiBold | Details hero name, quiz prompt, empty-state titles |
| titleLarge | Fraunces SemiBold, 22/28 | Screen titles, section headers |
| titleMedium / titleSmall | Roboto Medium | Row titles, card titles, dialog titles |
| body* | Roboto | Facts, descriptions |
| label* | Roboto Medium | Chips, buttons, overlines |

Fact labels use `labelSmall` with `letterSpacing = 1.sp`, uppercase via `String.uppercase(locale)`. Numbers use `NumberFormat` in the user's locale (already the case).

All sizes stay in `sp`. Fraunces sizes are never below 22 sp so the serif stays legible at 200% font scale on a compact width.

### 1.4 Spacing, shape, elevation

- Spacing scale: 4 / 8 / 12 / 16 / 24 / 32. Page gutter 16 dp on compact, 24 dp on expanded. List row min height 72 dp.
- Shapes: extraSmall 4, small 8, medium 12, large 16, extraLarge 24, extraLargeIncreased 32 (drop the 48 dp extraExtraLarge; nothing should be that round on paper). Flag plates: `small`. Cards and tiles: `medium`. Hero flag and map: `large`. Search field and chips: full pill.
- Elevation: 0 dp for cards and tiles (tonal layering). 3 dp shadow only on the FAB and the scrolled top app bar (Material default). Hairline rules: 1 dp `outlineVariant`.

### 1.5 Motion

- Keep `MotionScheme.expressive()`. Use `motionScheme.defaultSpatialSpec()` for layout moves and `defaultEffectsSpec()` for fades.
- Stack navigation: shared-axis X (slide 30 dp + fade) through `NavDisplay` `transitionSpec`/`popTransitionSpec`, and Material's predictive back through `predictivePopTransitionSpec`. Delete the extra `AnimatedContent` wrapper around `NavDisplay`.
- Press feedback: existing `pressScaleEffect` (0.97) on rows and tiles.
- Favorite toggle: existing scale bounce, tint to `tertiary`.
- Shimmer: keep, recolored to `surfaceContainerHigh`/`surfaceContainerHighest`.
- Reduced motion: Compose scales all durations by the system animator scale (`MotionDurationScale`), so "Remove animations" already snaps every animation. Verify on device with `adb shell settings put global animator_duration_scale 0`. No extra code.

### 1.6 Navigation and information architecture

Unchanged structure, sharper hierarchy:

- **Countries** (home). Top app bar with title "Countries" (Fraunces) and a subtitle line with the country count and last update. Actions: Quiz, Settings. Filters (`hasActiveFilters`) shows a "Clear" action. Search is a pill field under the bar. Region chips and sort live in one row. Alphabet jump index stays. Long-press enters compare selection; the bar switches to a `primaryContainer` contextual bar with count and "Compare".
- **Details.** Hero (flag plate, serif name, "Region · Capital" line, cache chip), fact grid, map card with "Open in Maps" action, nearby countries row, optional AI summary card. Actions: Share, Favorite, Refresh.
- **Quiz.** Score strip, mode picker as three cards, question card, answer options, result banner.
- **Compare.** Header with flag plates and names; striped fact table (compact) or one column per country (≥ 600 dp).
- **Settings.** Grouped sections, one card per section with `ListItem` rows, no per-row cards.
- **Expanded width (tablet, landscape foldable).** List pane fixed at 380 dp with a `VerticalDivider`; detail pane fills the rest. Details fact grid becomes three columns; map sits beside facts when width ≥ 840 dp.

```kotlin
// FlagImage.kt
fun flagDrawableName(twoLetterCode: String) = "${twoLetterCode.lowercase(Locale.US)}_flag"

@Composable
fun FlagImage(
    twoLetterCode: String,
    contentDescription: String?,
    modifier: Modifier = Modifier,
    shape: Shape = MaterialTheme.shapes.small,
) {
    val context = LocalContext.current
    val resId = remember(twoLetterCode) {
        context.resources.getIdentifier(flagDrawableName(twoLetterCode), "drawable", context.packageName)
    }
    Box(
        modifier
            .aspectRatio(3f / 2f)
            .clip(shape)
            .background(MaterialTheme.colorScheme.surfaceContainerHighest)
            .border(1.dp, MaterialTheme.colorScheme.outlineVariant, shape),
        contentAlignment = Alignment.Center,
    ) {
        if (resId != 0) {
            AsyncImage(
                model = ImageRequest.Builder(context).data(resId).crossfade(true).build(),
                contentDescription = contentDescription,
                modifier = Modifier.fillMaxSize(),
                contentScale = ContentScale.FillBounds,
            )
        } else {
            Text(twoLetterCode, style = MaterialTheme.typography.labelMedium)
        }
    }
}
```
